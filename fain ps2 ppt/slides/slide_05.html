1Birdsong Detection at the Edge with Deep Learning Disabato
2021		 Develop and evaluate lightweight deep learning models for real-time, on-device bird-call detection on resource-constrained edge hardware. CNN architectures trained on the BirdVox-DCASE-20k dataset, quantized, and deployed on ARM Cortex-M / embedded MCUs; benchmarked for latency, memory footprint, and accuracy. Edge-optimized CNNs achieved high classification accuracy while running in under 300KB with millisecond-scale inference, confirming fully on-device audio classification is feasible. Limited to bird-call presence/absence, not multi-class environmental threat sounds; no field validation in real forest deployment conditions.
2Low-Power Distributed Acoustic Sensor Network for Autonomous Wildlife Monitoring Using LoRa and AI De Miguel
2025		 Design a distributed, low-power acoustic sensor network for autonomous wildlife monitoring, integrating LoRa communication and AI-based classification into a digital twin framework. ESP32-based sensor nodes stream compressed audio over LoRa to a cloud server, where AI models classify wildlife sounds; evaluated for power consumption and detection accuracy. Demonstrated a working low-power LoRa + AI monitoring architecture with viable multi-day battery life and successful wildlife-sound classification in test deployments. Cloud-dependent inference streams compressed audio, risking LoRaWAN duty-cycle violations under frequent activity; no on-device inference explored.

SYNTHESIS & FAIN POSITIONING · Disabato (2021) validates on-device CNN feasibility; De Miguel (2025) demonstrates LoRa + AI integration but defers inference to the cloud. FAIN bridges this gap by combining 100% on-device TinyML inference with lightweight LoRaWAN telemetry.
